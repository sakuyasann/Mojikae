# 製品ページ

`index.html` は単一ファイルで完結する製品ページです。外部リクエストは GitHub へのリンクだけで、
書体も UI も内包しているためオフラインでも同じ見た目になります。

## 素材

ダミーのモックではなく、拡張機能の実物を使っています。

| ファイル | 中身 | 取得元 |
| --- | --- | --- |
| `assets/popup.css` | ポップアップのコンパイル済み CSS | `.output/chrome-mv3/assets/popup-*.css` |
| `assets/ui-selected.html` | ポップアップの DOM スナップショット（書体を選んだ状態） | 実行中のポップアップの `#root` |
| `assets/ui-search.html` | 同上（検索・絞り込みを開いた状態） | 同上 |

画像ではなく DOM と CSS をそのまま埋め込んでいるので、拡大しても滲まず、文字列としても選択できます。

## 書体

Google Fonts から取得し、**ページに実際に出る文字だけ**へサブセットして data URI で内包しています
（拡張機能が検索結果のプレビューで使っているのと同じ `text=` の仕組み）。9 書体で約 348KB。

## ビルド

```bash
node site/build.mjs
```

`index.template.html` に素材と書体を流し込んで `index.html` を生成します。
拡張機能の UI を変えたときは、`pnpm build` でコンパイル済み CSS を作り直し、
ポップアップの DOM スナップショットを撮り直してから再ビルドしてください。
