そのページが何を使っているか

DOM を走査して、実際に描画されている font-family を数え上げます。外部スタイルシートが読めない場合でも、 要素の computed style を見るので取りこぼしません。

差し替え

欧文と和文に別の書体を

選んだ順に font-family へ並べます。字形を持たない文字は次の書体へ送られるので、 英数字は欧文書体、日本語は和文書体という使い分けがそのまま成立します。

原状復帰

変更は開いているタブだけ。設定はページ内の data 属性にしか持たないので、 リロードすれば必ず元に戻ります。サイトのクラスや style は書き換えません。

That restraint is the whole product.

04

預かるものを、できるだけ少なく。

activeTab

アイコンを押したそのタブだけにアクセスします。tabs 権限は持たず、 他のタブや履歴には触れません。

scripting

書体の検出と、上書き CSS の出し入れに使います。

storage

保存するのは最近使った書体名とプリセットだけ。閲覧した URL・ページ内容・適用状態は保存しません。

host permissions

fonts.googleapis.com と fonts.gstatic.com のみ。 <all_urls> は使いません。

catalog

書体一覧は拡張機能に同梱しています。実行時に Google Fonts の API を呼ぶことはありません。
